## ⚡ Overview

**Volia** (meaning *Freedom*) gives you the freedom to easily extract and download videos, images, and audio from platforms like **YouTube, X (Twitter), Facebook, and Instagram**. 

This repository contains the sleek, responsive **React + Vite** frontend of Volia. It provides an intuitive experience designed to make downloading high-quality media effortless.

---

## ✨ Features

- **🎨 Premium UI/UX:** Built with modern design principles, featuring smooth micro-animations, glassmorphism, and a vibrant user interface.
- **🌗 Dark & Light Mode:** Seamlessly switch themes based on your preference.
- **📊 Real-time Progress Tracking:** Live download progress bar displaying downloaded size, ETA, and transfer speed.
- **🎥 Smart Format Selection:** Automatically categorizes media into *Video+Audio*, *Video Only*, and *Audio Only* streams with exact file sizes and resolutions.
- **📜 Download History:** Keep track of all your past downloads in a dedicated history panel.
- **🍪 Cookie Management:** Integrated settings to configure browser cookies for downloading private or age-restricted content.

---

## 🚀 How to Use Volia

Using Volia is designed to be as simple as possible:

1. **Copy the Link:** Find the video or audio you want to download (from YouTube, Twitter, Instagram, etc.) and copy its URL.
2. **Paste & Fetch:** Paste the URL into the Volia input bar on the Home page and hit Enter (or click Fetch).
3. **Select Quality:** Volia will display a card with the media details. Browse the available formats and select your desired quality (e.g., 1080p MP4, or Audio Only).
4. **Download:** Click the "Download" button! A progress bar will appear at the bottom showing your download speed and remaining time. Once finished, the file will automatically save to your device.
5. **Manage History:** Navigate to the History tab to see your previously downloaded files and clear them if needed.

## 🛠️ Installation & Setup

To run the frontend locally, make sure you have [Node.js](https://nodejs.org/) installed, and that the **Volia Backend** is running.

```bash
# 1. Clone the repository (if you haven't already)
git clone https://github.com/YasirAminBrohi/volia.git

# 2. Navigate to the frontend directory
cd volia/frontend

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The application will be available at `http://localhost:5173`. 

*(Note: The frontend expects the FastAPI backend to be running concurrently on port 8000. You can start both using the provided batch scripts in the root directory).*
